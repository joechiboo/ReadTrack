## 那該死的藍莓

作者請丈夫買藍莓，結果他空手回家。這不只是藍莓的問題，而是引爆了長期積壓的怨氣——她發現自己承擔了家裡幾乎所有的「心力勞動」（Mental Load）。

心力勞動不是洗碗、拖地那種看得見的勞動，而是那個永遠在背後轉不停的大腦 CPU——「記得」、「規劃」、「提醒」、「安排」。

---

## 專案經理 vs 工讀生

在家庭這間公司裡，常常一方是專案經理（負責構思、規劃、監督），另一方只是偶爾來支援的工讀生（聽命行事、做完交差）。

這種「一個腦力全開，一個坐等指令」的模式，是扼殺婚姻愛情的元兇。

---

## CPE 原則

這是全書精髓。真正「擁有」一張任務卡，代表你必須從 C 到 P 到 E 全程負責：

- **Conception（構思）**：誰先想起來要做這件事？
- **Planning（規劃）**：誰負責查資料、決定怎麼做？
- **Execution（執行）**：誰去做？

**只做 E 的人，不算真正擁有這張卡。**

## 我的實踐：四個家庭專案

### 1. 倒垃圾 ✓ 完整擁有

- **C**：睡前 + 睡醒觀察垃圾量
- **P**：配合作息決定丟垃圾時機，每月休假時去家樂福補貨
- **E**：自己丟、自己買垃圾袋

### 2. 洗衣服 ✓ 完整擁有

- **C**：觀察三個洗衣籃的滿度
- **P**：睡前預約洗衣 → 起床烘乾 → 週末收摺 → 制服優先歸位
- **E**：全流程自己執行

### 3. 送兒子上學 ✓ 公平分工

- **C**：記得幾點出門、餐袋內容
- **P**：前晚餐袋洗好、衣服位置清楚、建立固定流程順序（叫起床 → 換衣服 → 刷牙 → 早餐 → 吃藥 → 出門）
- **E**：我負責大兒子，太太負責小兒子

### 4. 洗碗 ✓ 完整擁有

- **C**：回家看到碗堆積、兩個兒子的餐袋要處理
- **P**：每天 20:30 回家後一併處理
- **E**：洗碗 + 清洗餐袋

## 爆點：太太還是覺得被壓榨

我本來覺得分工還算公平。我負責庶務，太太收入略高、負責小孩的大小事。我執行力強，照單全收，隨時可以調換家務。

但太太還是覺得被壓榨。

讀完這本書才意識到：**我做的是 E，但 C 的重量一直在她肩上。**

太太給我的是一份「待辦清單」，這代表她還是在做 C 和 P。爸爸生日要辦聚餐？她想到、她規劃，我只是去執行。這些「想」的工作看不見、沒有人按讚，但很累。

**真正減輕她的負擔，不是「你叫我做什麼我就做」，而是主動把一些 C 扛過來。**

## 行動計畫：承擔更多 C

### 近期（馬上可做）

把現有庶務的 C 做得更主動：

- **日用品**：注意到牙膏沒了 → 馬上加入購物車 ✓ 已完成
- **藥包**：固定位置 + 自己注意到快沒了
- **衛生紙、洗碗精、洗衣精**快沒了也自己注意

連結《小狗錢錢》的 72 小時法則：注意到了 → 72 小時內沒行動 → 通常就不會做了。

### 中期（建立系統）

把「太太腦中的待辦」轉移到自己的系統：

- 建立行事曆：家人生日、學校行事曆、繳費日、定期事務
- 設定提前提醒，從「等太太想起來告訴我」→「自己會被提醒」

已開始建立 2026 年行事曆 ✓

### 遠期（整張卡拿走）

挑幾張「完整的卡」從太太手中接過來：

- **我這邊的家族關係**：爸媽的生日、過年過節安排
- **小孩的某個面向**：例如大兒子的才藝課
- **家庭採買**：每週或每月固定補貨，不用太太開清單

---

## 結語

公平分工不是「各做 50%」，而是：

- 雙方都認可這個分配
- 沒有人覺得被壓榨
- 心力勞動有被看見

我的庶務做得不錯，但太太累的是 C——永遠要「記得」、「想到」、「規劃」。

**下一步：不只是做好 E，而是主動承擔更多 C，讓太太腦中的待辦清單少一點。**

## 與其他書的連結

### 《小狗錢錢》

- 72 小時法則：注意到了就馬上行動，不要拖延
- 應用在家務上：看到快沒了 → 馬上處理

### 《Scrum》

- CPE 原則很像 Scrum 的任務擁有權
- 真正擁有一張卡 = 從 Planning 到 Done 全程負責

### 《The Let Them Theory》

- 有些事要 Let Them，但家庭分工不能 Let Them
- 該承擔的 C 要主動扛起來
